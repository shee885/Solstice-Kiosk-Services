Check-In Kiosk

Tap "Scan Badge" for each attendee. The badge now prints on a queue — the screen shows Printing… until the printer's webhook confirms, then flips to Checked In. Try tapping Scan twice fast on one attendee — the second tap is blocked, not a second badge.

Live event log

This simulates the real service: Scan Badge = the check-in call (returns "pending" immediately, no more waiting on the printer). A few seconds later a simulated webhook fires and flips the status — same as the vendor's printer calling back. Scanning again while a print is already pending is blocked, so a duplicate scan can never trigger a second badge.
